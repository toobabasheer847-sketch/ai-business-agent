# Frontend — AI Business Agent

React + TypeScript + Vite dashboard for the NestJS backend in the repository root.

## Stack

- React 19 + TypeScript + Vite
- Tailwind CSS v4 + shadcn/ui
- TanStack Query + Axios
- React Router + Framer Motion
- Zod + React Hook Form

## Setup

```bash
cd frontend
npm install
cp .env.example .env
npm run dev
```

Default URL: http://localhost:5173

Backend expected at `VITE_API_URL` (default `http://localhost:3000/api`).

## Phase 1 scope

Foundation only: providers, auth shell, API client, dashboard layout, module placeholders.

Business modules will be implemented one-by-one after plan approval.
